---
description: 智能路由（模糊意图 → 分发到对应命令）
---
按用户意图分发到对应命令。参数：$ARGUMENTS（用户的模糊需求）

用户没明确指定哪个命令时，分类意图后建议/调用对应命令：

| 意图关键词 | 命令 |
|---|---|
| 日志 / 报错 / 崩溃 / 定位到代码行 | `/diag` |
| bug 报告 / 失败现象（非日志）/ 根因 | `/bug-trace` |
| 需求 / 设计 / feature | `/feature-design` |
| 生成结构 wiki / 建图 / sync | `/graph-sync` |
| 架构文档 | `/arch-doc` |
| 业务流 / 错误目录 / error_index | `/flow-doc` |
| 归档案例 / 存经验 | `/exp-archive` |
| 查历史 / 见过吗 / 经验检索 | `/exp-search` |

若意图明确 → 直接告诉用户用对应 `/命令`（或你直接代为执行）。若模糊 → 列出最可能的 2-3 个命令让用户选。用户也可直接 `@<agent名>` 手动调单 agent。
